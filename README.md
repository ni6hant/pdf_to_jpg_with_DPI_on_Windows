# PDF to JPG Converter (Windows) 0.8
Quick and fast way to convert PDF to JPG. Running it from path makes it very quick to use.

## Install & Use
0. Download the [executable from releases page](https://github.com/ni6hant/pdf_to_jpg_with_DPI_on_Windows/releases).
1. On Windows, first put this executable in [your PATH](https://youtu.be/SD4g1OaUFXA).
2. Then in Explorer, open the folder of JPGs you want trimmed. Click the address bar, type: `pdftojpg`.

## LLM ≤0.7
LLM was used in versions 0.7 and before but not with versions 0.8 and above.
